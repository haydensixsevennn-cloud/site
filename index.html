    How to Use AI Properly

    Getting good results from AI isn't simply about typing "make me a website" or "write me a game". AI performs infinitely better when you supply actionable context, explicit tech stacks, logic bounds, and clear constraints.

    01. Comparing Prompts

    ❌ BAD PROMPT VAGUE

    "make me a minecraft game"

    Why it fails: AI has to guess the language, 2D vs 3D, libraries, controls, graphics engine, feature scope, and file architecture. It usually gives generic snippet skeletons.

    ✅ BETTER PROMPT STRUCTURED

    "Create a browser-based Minecraft-inspired voxel game using HTML, CSS and JavaScript. Use Three.js for rendering. Include procedural terrain generation, WASD movement, mouse-look controls, block placement/removal and an inventory system. Keep everything in a single HTML file..."

    Why it works: Clear tech choices (Three.js), exact features, input mechanisms, and architecture constraint (single HTML file).

    02. The 7 Core Components of a Great Prompt

    1. Tell the AI what you're building

    Clearly define the end goal (e.g., "A lightweight server plugin for inventory sorting").

    2. Explain the technology stack

    HTML/CSS/JS, Python, Three.js, Roblox Studio, Minecraft Bedrock, Java, UEFN.

    3. Explain exactly what you want

    List core mechanics line by line instead of vague summaries.

    4. Give strict constraints

    "Single HTML file", "Vanilla JS", "No external backend", "Must work on Bedrock".

    5. Explain desired visual style

    Theme, colors, layout, spacing, dark UI, rounded corners, responsive layout.

    6. Explain existing code context

    Provide existing scripts and explicitly note what must remain untouched.

    7. Explain what went wrong (Useful Debugging)

    Instead of "it doesn't work", say: "When I click Create World, nothing happens. No console errors appear, and the button doesn't trigger world generation."

    03. The Master Prompt Formula

    ROLE + GOAL + CONTEXT + REQUIREMENTS + CONSTRAINTS + DESIGN + OUTPUT

    // Example Prompt Template Structure:

    Act as an experienced JavaScript game developer.

    I am building a browser-based voxel game using HTML, CSS and Three.js.

    Requirements: Procedural terrain, WASD controls, inventory bar.

    Constraints: Everything must be inside one runnable HTML file. Don't remove existing movement logic.

    Design: Dark UI HUD, clean modern layout.

    Output: Provide the complete code and explain key changes made.

    04. AI Is an Iterative Cycle

    Don't expect one giant prompt to produce a flawless end product. Build iteratively:

    Idea → First Version → Test → Identify Problems → Feedback to AI → Fix & Improve
    Useful follow-up prompt examples:
    • "That fixed the issue, but now the inventory overlaps the hotbar. Fix only that problem without changing anything else."
    • "Keep everything currently working. Add sprinting without rewriting the movement system."
    • "Explain why this error is happening, then show me the smallest fix."

    05. AI Do's & Don'ts

    DO
    • ✓Be specific and give context
    • ✓Explain explicit tech & constraints
    • ✓Include exact error messages
    • ✓Test each iteration carefully
    • ✓Break large tasks into smaller steps
    • ✓Ask AI to explain unfamiliar code
    DON'T
    • ✗Give extremely vague 3-word prompts
    • ✗Expect perfection on the first try
    • ✗Copy code without testing it
    • ✗Ask for 100 complex features at once
    • ✗Hide error logs or console messages
    • ✗Delete working backups before testing
